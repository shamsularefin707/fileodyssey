The first release of FileOdyssey: an offline file and image toolkit for Windows, Linux and Android. Your files never leave your device.

**What it does**
- **Convert documents**: Markdown, Word, OpenDocument, HTML, EPUB, RTF, LaTeX, plain text and more (Pandoc, built in), with a report of what was kept on every conversion.
- **PDF to Word, Markdown, HTML and more**: rebuilds headings, paragraphs, lists, tables, footnotes and images; Word output keeps fonts, sizes and colours. Marked "best effort", with an honest report.
- **With LibreOffice installed (desktop)**: old .doc/.xls/.ppt files, and Office files to PDF with their exact layout.
- **Images**: convert between formats, compress, resize, read QR codes, combine into a PDF.
- **Compress**: archives (ZIP, 7z, TAR…), PDFs and Office files.
- **Read**: PDF, EPUB, Word and other documents, and images, in a built-in reader.
- **Android**: scan documents (Google ML Kit) and QR codes with the camera.

**Downloads**: see "Which file do I need?" in the [README](https://github.com/shamsularefin707/fileodyssey#download). Check a download against `SHA256SUMS`.

**Good to know**
- Windows shows a SmartScreen warning because the installer isn't code-signed: choose "More info" → "Run anyway".
- Android: allow installing from your browser or file manager when asked. The document scanner needs Google Play services.
- The only internet use is an optional check for new versions, which you can turn off under "About FileOdyssey".
