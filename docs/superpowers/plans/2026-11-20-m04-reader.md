# M4 — Reader Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** A read-only Read tab: PDF (render, thumbnails, zoom, search, select/copy text), EPUB (chapters, font size), TXT/MD, sanitised HTML, images (zoom, EXIF).

**Architecture:** Parsing and rendering live in `fo-core::reader` behind a `Sessions` store keyed by doc id. PDFium runs on one worker thread (`PdfEngine`). The Tauri shell exposes `reader_*` commands plus a `reader` URI-scheme protocol that serves page bitmaps, book resources and image bytes, so the UI uses plain `<img loading="lazy">`. The Leptos UI gets a `reader` component family; the mock backend supplies sample docs for browser preview.

**Tech Stack:** pdfium-render 0.9.5 (`pdfium_8125`, `image_025`, `thread_safe`) + bblanchon pdfium-binaries `chromium/8125`; ammonia 4; pulldown-cmark 0.13; quick-xml 0.42 (with `serialize` off); kamadak-exif 0.6; chardetng 1 + encoding_rs 0.8.

**Spec:** `docs/superpowers/specs/2026-11-19-fileodyssey-toolkit-design.md` §5.2, §6.2; roadmap row M4.

## Global Constraints
- Read-only. No network: sanitised HTML keeps no remote URLs; CSP forbids them.
- Engines in `fo-core`; `fo-types` stays wasm-safe.
- DOCX/ODT/RTF reading is M5 (show "Reading Word and OpenDocument files arrives with document conversion").
- Copy rules: sentence case, plain verbs, errors say what happened and what to do.
- Protocol serves only docs opened this session (unknown id → 404).
- PDF render width capped at 4096 px; search hits capped at 500; text files capped at 20 MB; EPUB resource ≤ 50 MiB; image display long edge ≤ 8192 px.

## Review Focus
1. Hostile EPUB/HTML: `<script>`, `on*=` handlers, `javascript:` links, remote `<img>`/CSS, `../` resource paths → all neutralised.
2. Encrypted/corrupt PDFs and DRM EPUBs → clear error, no panic, worker survives.
3. Non-UTF-8 text (UTF-16 BOM, windows-1252) and Bengali UTF-8 decode correctly.
4. Protocol: unknown doc id, page out of range, bad width, `res/../../etc/passwd` → 4xx, never a file outside the book/doc folder.
5. Huge PDFs (1000+ pages) stay responsive: lazy page images, info call doesn't render.
