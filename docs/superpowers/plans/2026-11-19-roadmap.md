# FileOdyssey — Module Roadmap

**Spec:** `docs/superpowers/specs/2026-11-19-fileodyssey-native-toolkit-design.md`

The spec covers several independent subsystems. Each module below gets its own
detailed plan (`docs/superpowers/plans/<date>-mNN-<name>.md`), written when the
module starts, and each one is sized to fit **one ~5-hour working session**.
Every module ends with working, tested software on `main`.

| # | Module | Delivers | Depends on | Spec § |
|---|---|---|---|---|
| M1 | **Foundation & UI shell** | Cargo workspace; shared types; file-type detection; `Tool` trait, registry, job runner with cancel and safe output naming; Tauri 2 app + Leptos UI shell in the organic design (tabs, drop zone, job list, report drawer); mock backend for browser preview; GPL-3.0 + ML Kit exception licence; CI (test + Win/Linux/Android builds) | — | 5.1, 5.3, 8, 9, 10 |
| M2 | **Images** | Decode/encode every format in §6.4 (except HEIC on Android → M8), resize, compress, target-size mode, metadata keep/strip, animated GIF/WebP, image → PDF; QR decoding from files (`rxing`) | M1 | 5.2, 6.4 |
| M3 | **Archives & compression** | ZIP/7z/tar.* create and extract (zip-bomb and path-traversal guards); PDF compression presets (`lopdf`); Office/EPUB image recompression | M1, M2 (image recompression) | 6.1, 9 |
| M4 | **Reader** | PDF reader (PDFium render, thumbnails, search, copy), EPUB, TXT/MD, sanitised HTML, image viewer with EXIF; DOCX/ODT/RTF reading is finished in M5 | M1 | 6.2 |
| M5 | **Pandoc conversions & fidelity** | pandoc.wasm under wasmtime (spike vs webview first); all Pandoc pairs from §6.3; fidelity report metrics; golden corpus + round-trip tests + CI gate; DOCX/ODT/RTF reader; CSV↔JSON, CSV→XLSX | M1, M4 | 5.2, 6.3, 7 |
| M6a | **PDF reconstruction I** | PDFium structured text → reading order (multi-column), paragraphs, headings, lists, images, links → intermediate doc → MD/HTML via Pandoc | M5 | 5.2, 7.6 |
| M6b | **PDF reconstruction II** | Tables (ruled + whitespace grids, merged cells), footnotes, headers/footers, direct DOCX via `docx-rs` with fonts and colours; meet the §7.6 bar on the corpus; scanned-PDF handling | M6a | 5.2, 7.5, 7.6 |
| M7 | **LibreOffice & PDF output** | `soffice` detection and headless conversion (desktop); legacy Office formats; Office → PDF; best-effort PDF output via Typst or webview print (pick after comparing) | M5 | 5.2, 6.3 |
| M8 | **Android scanning** | `tauri-plugin-barcode-scanner` QR/barcode flow with result actions; `tauri-plugin-docscan` (Kotlin, ML Kit) → JPEG + PDF; scan history; HEIC via `ImageDecoder`; share-sheet / "Open with" targets | M1, M2 | 6.5, 5.2 |
| M9 | **Release v1.0.0** | Tauri updater with signed manifests; Android update notice; release workflow on `v*` tags (NSIS/MSI, AppImage/.deb, signed APKs); README, SmartScreen note, third-party licences; final corpus check | all | 8 |

M2, M3 and M4 are independent of each other after M1 and can be done in any order.
No public release until M9 (one v1.0.0 release, per the spec).
